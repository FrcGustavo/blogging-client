Hola mi nombre es Gustavo y quiero enseñarte algunos de los proyectos en los que he trabajado este año 2021.

## **Coco Netflix**

Este proyecto muestra un listado de películas muy parecido al de Netflix, cuando das clic sobre alguna card te muestra el tráiler de la película, esta creado con React JS, CSS, y consume un API de películas.

![](https://res-2.cloudinary.com/hgzzjqqrw/image/upload/q_auto/v1/ghost-blog-images/coconetflix.png)

## **Coco Amazon**

Este proyecto es una tienda en online muy parecida a Amazon puedes crear tu cuenta e iniciar sesión, agregar tus productos al carrito ver el total y hacer le pago, las tecnologías que utiliza son, React JS, CSS, firebase y stripe.

![](https://res-5.cloudinary.com/hgzzjqqrw/image/upload/q_auto/v1/ghost-blog-images/cocoamazon.png)

## **Blogging**

Blogging es el blog donde comparto el conocimiento y práctica que he adquirido con el tiempo, haciendo un pequeño aporte a internet.

Esta construido con Next JS y utiliza diferentes estrategias de renderizado para ofrecer la mejor experiencia, también utiliza styled-components y consume un api construida en express con TypeScript.

![](https://res-4.cloudinary.com/hgzzjqqrw/image/upload/q_auto/v1/ghost-blog-images/blogging_home.png)
